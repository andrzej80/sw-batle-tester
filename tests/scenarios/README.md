Сценарные тесты: приложение целиком на файле сценария, сравнение с эталоном.

Каждый каталог — один сценарий:

| Файл | Содержимое |
|---|---|
| `scenario.txt` | входной сценарий |
| `expected.out` | ожидаемый stdout (события) |
| `expected.err` | ожидаемый stderr (ошибки, сообщения); путь к файлу — `scenario.txt` |
| `expected.code` | ожидаемый код выхода |

Сценарии проверяются дважды:

- `GoldenScenarios_match_expected_output` (`sw_tests`) — внутри процесса, со случайностью-
  заглушкой (`FirstRandom`), как требует SPECIFICATION.md, п. 11;
- `scenario.<имя>` (ctest) — настоящий `sw_battle_test` со `StdRandom`
  (`cmake/RunScenario.cmake`).

Совпадение обоих возможно, потому что сценарии составлены без случайного выбора: у
каждого действия одна подходящая цель и одна подходящая клетка. Новый сценарий
должен соблюдать это правило — иначе исполняемый файл даст другой, но тоже верный вывод.

Добавить сценарий: создать каталог с четырьмя файлами — регистрировать нигде не нужно.
