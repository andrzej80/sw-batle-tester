# Мина (Mine)

Статус: согласовано, реализовано (задача [T29](../stage3/T29-mine.md));
пункты приёмки с пометкой (T30) проверены в T30.

README: Power; не может быть атакована; не занимает клетку; если в радиусе 2 клеток есть
юнит — взрывается в следующем ходу, нанося всем юнитам в радиусе 3 клеток **Power**
урона; после взрыва исчезает; не может перемещаться.

## Команда

`SPAWN_MINE unitId x y power` — `io::SpawnMine` (согласовано, С1). Поля `hp` нет.

## Проверки

| Поле | Условие | Код |
|---|---|---|
| `power` | ≤ 0 | `unit.invalid_stat` |

(согласовано, С4). Мина не занимает клетку: её можно поставить на занятую клетку, и на её
клетку можно встать.

## Сборка

`MineSpec{id, position, power}` → `makeMine`:

- `occupiesCell = false`;
- компоненты: `Power(power)`; **без** `Health` и **без** `Movement`;
- behaviour = [`MineFuse`]. Тег `explosion` объявляется в файле фичи (архит. 4.9), `area` —
  из `Features/Common/CommonTags`.

Следствия сборки, без отдельных правил:

- без `Health` Мина не бывает целью урона и лечения — `Targeting` отфильтровывает её сам
  (спец. 5.2): «не может быть атакована»;
- без `Movement` Мина статична: `MARCH` на неё — `march.unit_cannot_move`.

## `MineFuse`

Состояние «взведена» хранится в объекте действия (Features README, контракт `IAction`).

```
взведена                                             → false (мир не меняется)
нет юнита с Health на дистанции 0..2 (ctx.query())   → false
иначе: взвести; ctx.schedule(tick + 1, self.id(), взрыв); true
```

- Взводится от любого живого юнита с `Health`, в том числе от летающего; другая Мина её
  не взводит — у неё нет `Health` (архит. 8).
- Задача взрыва захватывает **только `UnitId` мины** (контракт архит. 4.13), не указатель
  на мину и не на действие, и копию источника урона `stat<Power>` — это значение.
  `Power` читается в момент взрыва; отрицательный (будущий дебафф) бьёт на 0, как у атак.
- `MineFuse` и тег `explosion` лежат в `Features/Units/Mine.cpp`, событие `MineExploded` —
  в `Mine.hpp`: пока они нужны только Мине.

Взрыв (фаза Scheduled тика N+1):

```
мина = query().find(id); нет → ничего не делать
publish(MineExploded{id})                                     // согласовано, С5
цели = targeting().select(мина, attack({area, explosion}, {0,3}))
каждой цели в порядке создания: effects().apply(Hit{spec, мина, цель, Power})
requestRemoval(мина)
```

- Бьёт **всех** целей, без случайного выбора — в том числе того, кто её взвёл, и
  летающих (правило `Flying` не трогает `area`). Другие мины не задевает.
- Если взводивший юнит ушёл или погиб, взрыв всё равно происходит; без целей Мина
  исчезает, задев никого.
- Погибшие получают `UNIT_DIED` сразу и в фазе Main этого тика не ходят (спец. 6.4).
- Мина и погибшие удаляются в Cleanup тика N+1. Пока взрыв в очереди, симуляция не
  останавливается «пустым тиком» (спец. 6.4).
- Мина считается юнитом в условии «живых ≤ 1» (архит. 4.6): Мина и один юнит вне радиуса
  — два юнита, остановка `NothingHappened`.

## Вывод

- `UNIT_SPAWNED … unitType=Mine …` (согласовано, С2).
- `MINE_EXPLODED unitId=<id мины>` (согласовано, С5) — событие фичи: структура
  `MineExploded` в Features, публикация через `ctx.publish`, DTO `IO/Events/MineExploded.hpp`,
  адаптер `App/Output/MineExplodedOutput.cpp` с `SW_REGISTER_OUTPUT`. Выводится до ударов
  взрыва, даже если никого не задело.
- Удары — `UNIT_ATTACKED` с `attackerUnitId` = id мины. Исчезновение Мины отдельного
  события не даёт: у неё нет `Health`, поэтому нет и `UNIT_DIED`.

Пример: Мина 1 с `power 5`, Мечник 2 с `hp 10` идёт по маршу мимо неё.

```
[3] UNIT_MOVED unitId=2 …        — Мечник на дистанции 2; Мина в этом тике уже ходила
[4] UNIT_MOVED unitId=2 …        — Мина взвелась (события нет), Мечник идёт дальше
[5] MINE_EXPLODED unitId=1
[5] UNIT_ATTACKED attackerUnitId=1 targetUnitId=2 damage=5 targetHp=5
[5] UNIT_MOVED unitId=2 …
```

Юниты ходят в порядке создания, поэтому Мина видит юнита, подошедшего после её хода,
только в следующем тике. Взвод в выводе не виден: это выполненное действие без события.

## Приёмка

- `power = 0` — `unit.invalid_stat`; `MARCH` на Мину — `march.unit_cannot_move`;
- Мину не выбирают целью ни Мечник, ни Охотник; на клетку Мины можно встать;
- не взводится от другой Мины; взводится от юнита на дистанции 2, не на 3, в том числе
  от юнита без `occupiesCell`;
- взрыв в следующем тике бьёт всех с `Health` на дистанции 0..3, не бьёт на 4; первым —
  `MINE_EXPLODED`;
- убитые взрывом получают `UNIT_DIED` в фазе Scheduled и в Main не ходят;
- Мина убирается в Cleanup тика взрыва;
- взведённая Мина — `false`, `world.activity().changes()` не изменился;
- пока взрыв в очереди, остановки `NothingHappened` нет;
- взводивший ушёл из радиуса 3 — `MINE_EXPLODED` без ударов, Мина исчезает;
- Мина и один юнит вне радиуса — остановка `NothingHappened`;
- (T30) взрыв задевает Ворона; Ворон взводит Мину.
