# Ворон (Raven)

Статус: согласовано, реализовано (задачи [T25](../stage3/T25-melee-distance.md),
[T28](../stage3/T28-raven.md));
пункты приёмки с пометкой (T30) проверены в T30.

README: HP, Agility; летающий: не занимает клетку, перемещается на 2 клетки за ход, не
может быть атакован в ближнем бою, в дальнем бою минимальная и максимальная дистанция
атаки по нему снижена на 1; «Удар когтем» — бьёт одного случайного юнита в соседних
клетках, нанося **Agility** урона; если некого бить, перемещается.

## Команда

`SPAWN_RAVEN unitId x y hp agility` — `io::SpawnRaven` (согласовано, С1).

## Проверки

| Поле | Условие | Код |
|---|---|---|
| `hp` | ≤ 0 | `unit.invalid_stat` |
| `agility` | ≤ 0 | `unit.invalid_stat` |

Обе ошибки выводятся вместе (согласовано, С4). Ворон не занимает клетку, поэтому
`unit.cell_occupied` при его спавне не бывает (спец. 7, `SpawnRequest`).

## Сборка

`RavenSpec{id, position, hp, agility}` → `makeRaven`:

- `occupiesCell = false`, тег `flying` (`Features/Common/CommonTags`);
- компоненты: `Health(hp)`, `Agility(agility)`, `Movement(2)`, правило цели `Flying`;
- behaviour = [`MeleeAttack(stat<Agility>, distance(0, 1))`, `MarchStep`].

## Правило цели `Flying`

Компонент `final`, реализует `ITargetRule` (контракт — архит. 4.13). Объявлен в
`Features/Units/Raven.hpp`: пока он нужен только Ворону, он лежит рядом с ним.

```
intent != Hostile      → дистанция без изменений   // лечение, баффы
теги содержат melee    → nullopt                   // ближний бой запрещён
теги содержат ranged   → range.shifted(-1, -1)     // {2,R} → {1,R-1}
иначе                  → без изменений             // area (взрыв Мины)
```

## Поведение

- **Удар когтем** — `MeleeAttack` с дистанцией `{0,1}` (теги `melee`, `physical`): Ворон
  может стоять на клетке цели, и `{1,1}` её бы не достал (архит. 8). Цель случайная,
  урон `Agility`. Нет целей — `MarchStep`.
- **Ворон не бьёт Ворона** (согласовано, С6): удар когтем — ближний бой, а правило
  `Flying` его запрещает.
- **Движение:** до 2 шагов за тик по правилам марша (спец. 6.3). Для юнита без
  `occupiesCell` любая клетка карты свободна (спец. 4.3), поэтому Ворон пролетает над
  занятыми клетками и может закончить марш на клетке, занятой другим юнитом.
- **Под атаками:** Мечник и ближний удар Охотника по Ворону невозможны; выстрел Охотника
  достаёт на 1..R−1, Башни — на 1..4; взрыв Мины (`area`) задевает Ворона; Ворон взводит
  Мину ([Mine.md](Mine.md)).
- Ворон не мешает выстрелу Охотника: `RequireNoAdjacentOccupying` учитывает только юнитов
  с `occupiesCell` (спец. 9.2).

## Вывод

`UNIT_SPAWNED … unitType=Raven …` (согласовано, С2); удар — `UNIT_ATTACKED`; движение —
`UNIT_MOVED` на каждый шаг, `MARCH_*` — как у остальных.

## Приёмка

- `hp = 0, agility = 0` — две ошибки `unit.invalid_stat` одним списком;
- `Flying::adjust`: `Hostile` + `melee` → `nullopt`; `Hostile` + `ranged` `{2,4}` →
  `{1,3}`; `Hostile` + `area` — без изменений; `Beneficial` — без изменений;
- Мечник рядом с Вороном его не бьёт; Охотник стреляет в Ворона на дистанции 1..R−1, на
  R — нет; Ворон рядом с Охотником выстрелу не мешает;
- Ворон бьёт `Agility` юнита на своей клетке и в соседней; Ворона не бьёт;
- за тик проходит 2 клетки, пролетает над занятыми, может остановиться на занятой;
- `MARCH` на Ворона принимается; Ворона можно заспавнить на занятую клетку;
- (T30) Башня по Ворону — дистанция 1..4; взрыв Мины задевает Ворона; Ворон взводит
  Мину; Лекарь лечит Ворона.
